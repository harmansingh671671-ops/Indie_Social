# Repository instructions

- **Before starting anything in this repo, read `context.md` once.** Do not re-read it
  repeatedly during the session; rely on your notes from that single read.
- **Before every commit, update `context.md`** with the important changes/done items so the
  next agent can understand the workflow. Include the update in that commit.
- **If `context.md` grows past 15,000 words, compress it** — keep what still matters and make
  it more concise.
- Run `npm run typecheck` and `npm run build` before committing.
